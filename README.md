# Mobilador Pro

Mapeador de teclado e mouse USB para Android.

## Instalar

[Baixar MobiladorPro.apk — versão mais recente](https://github.com/Balanca02/MobiladorPro/releases/latest/download/MobiladorPro.apk)

Instale por cima da versão anterior para preservar as configurações. O identificador do aplicativo é br.com.mapausb. O serviço de acessibilidade aparece como Mobilador Pro · Controles.

## Atualizações

A partir da versão 0.4.81, o app consulta novas versões ao abrir. Também é possível usar Perfil → Verificar atualização. Quando existir uma versão nova, o app oferece o download e abre a instalação do Android, que pede confirmação.

As versões anteriores precisam instalar a 0.4.81 uma vez pelo link acima para receber essa função.

## Dados e acessos

A acessibilidade recebe teclado/mouse e executa toques configurados no jogo. Teclas, alvos e ajustes ficam no aparelho. Esta versão não captura imagens da tela. A conexão com a internet consulta este repositório e baixa os APKs quando solicitado; o app não envia o perfil ao servidor.

O atualizador confere SHA-256, identificador do pacote, versão e assinatura antes de oferecer a instalação. Este repositório distribui APKs; não contém a chave de assinatura nem os perfis pessoais dos jogadores.
